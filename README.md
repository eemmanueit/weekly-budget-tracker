# Personal Weekly Budget Tracker & Expense Analyzer

This is a terminal-based Python application designed to help users track their weekly expenses, compare their spending against a set budget limit, and analyze their expenditure habits. 

I developed this program as part of my Python programming coursework to solve a common, everyday problem: helping college students and young professionals manage their limited weekly funds and avoid unexpected overspending.

## Key Features

- **Robust Input Validation:** The program utilizes exception handling (try-except blocks) inside input loops to prevent crashes. If a user enters letters, empty spaces, or negative values for budget limits or expense costs, the system catches the error and prompts them again.
- **Dynamic Data Collections:** It uses Python lists and dictionary structures to store and track an unlimited number of expenses dynamically during a single session.
- **Calculated Spending Statistics:** At the end of the session, the program automatically calculates:
  - Total money spent
  - Remaining balance (displaying a warning if the user went over budget)
  - Average cost per expense
  - The name and cost of the highest single expense recorded
- **Persistent Text Logging:** It automatically appends a complete, timestamped report of every budgeting session to a local file named `budget_history.txt`. This allows users to look back at their spending habits over multiple weeks.

## File Structure

- `budget_tracker.py` - The main Python script containing the program logic, validation functions, and user interface loop.
- `budget_history.txt` - The persistent log file generated by the program to save historical session summaries.
- `README.md` - Documentation explaining the project.
